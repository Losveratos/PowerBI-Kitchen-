Daten-WG Knowledge Kitchen · Workflow

Vom Whiteboard zur Power-BI-Seite

Drei Schritte, drei Werkzeuge: gemeinsam klären, verbindlich festlegen, automatisch bauen. Jeder Schritt übergibt eine Datei an den nächsten.

1

Claude-Whiteboard

Klären · alle gleichzeitig
  • Auftrag: Zielgruppe, Zweck, Entscheidung
  • Je Berichtsseite eine Leitfrage
  • Kacheln als Blöcke: Titel, Typ, Lage, Größe
  • Gelb = offen, Grün = abgestimmt
Ergebnis: bemaltes Board mit Seiten-Skizzen
Board
auslesen
2

MockupKitchen

Festlegen · eine Person
  • Skizze kommt als Raster an, nichts wird abgetippt
  • Kachel-Typ wählen, Felder ans Modell binden
  • Prüfungen: Pflichtfelder, Raster, Barrierefreiheit
  • Läuft im Browser, ohne Konto und Server
Ergebnis: mockup-spec.json, Agent-Brief, Workshop-Doku
Spec
Export
3

Claude Code

Bauen · der Agent
  • Spec prüfen, Plan zeigen, auf Freigabe warten
  • Seiten, Visuals, Slicer, Navigation anlegen
  • Neue Kennzahlen im Modell ergänzen
  • Abnahme gegen das Sollbild
Ergebnis: Power-BI-Bericht im PBIP-Projekt
Rückweg für die Review-Runde: Ein fertiges Mockup lässt sich wieder als Board auslegen, damit alle kommentieren. Ein zweiter Baulauf ändert nur, was sich geändert hat.

Was der Ablauf bringt

Erst die FrageJede Seite beginnt mit ihrer Leitfrage, nicht mit einem Diagrammtyp.
Alle arbeiten mitAuf dem Board schieben und kommentieren alle zugleich, statt einer Person beim Klicken zuzusehen.
Kein AbtippenLage und Größe der Blöcke werden übernommen. Im Test lagen die Kacheln höchstens 6 px daneben.
Geprüft vor dem BauFehlende Felder, zu kleine Kacheln und offene Fragen fallen im Mockup auf, nicht im fertigen Bericht.
WiederholbarDieselbe Spec ergibt denselben Bericht. Jeder Lauf ist nachprüfbar.

Grenzen: Das Board kennt kein Datenmodell, Felder werden erst in MockupKitchen gebunden. Fehlt der Typ auf einem Block, wird er geschätzt und als offene Frage markiert. Filterbereich, Navigation und Gestaltung kommen nicht vom Board. Der Schritt Board → MockupKitchen ist bisher an einem Demo-Board getestet.

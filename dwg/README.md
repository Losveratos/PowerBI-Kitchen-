# dwg (Arbeitsname dwg cli) · umgezogen

Adapter `@dwg/visuals`, App-Generator und PBIP-Generator liegen jetzt zusammen im Repo **Fabric-Apps-Demo** unter
`dwg/` (Einstieg `node dwg/dwg.mjs`). Der Adapter baut ChartKitchen (`ibcsInspiredChartDeck/`) und P&L
(`pnlByDatenWG/`) aus einem Klon dieses Repos, Pfad über `DWG_KITCHEN` oder `--kitchen`.

Plan und Stand: [`sessions/plan-kitchen-fabric-apps.md`](../sessions/plan-kitchen-fabric-apps.md).

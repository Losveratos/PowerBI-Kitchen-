# Bookmarks

In einem US-Police-Beispiel-Dashboard wird beim Klick auf ein Bundesland wie Kalifornien automatisch der zugehörige Navigations-Button deaktiviert, um den aktiven Filter anzuzeigen. (Stand 2022-02) Eine Navigationsleiste zum Wechseln zwischen einzelnen Seiten wird mit Bookmarks umgesetzt. (Stand 2022-02) Der Fokus-Modus eines Visuals lässt sich als Bookmark speichern und über einen Button auslösen. (Stand 2022-02)

# DAX Studio

Anders als im Import-Modus zeigt Direct Lake keine Speicherstatistik im Datenmodell an, solange keine Abfrage die Daten tatsächlich geladen hat. (Stand 2025-08) Die abschließende Schulungseinheit zu Drittanbieter-Tools behandelt unter anderem den Tabular Editor, Object Level Security und DAX Studio. (Stand 2022-06)

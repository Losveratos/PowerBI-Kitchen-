# Update

Der Input Slicer, vormals Textslicer, ist im Power BI Update vom Februar 2026 generally available geworden. (Stand 2026-02) Seit einem Update im Januar merken sich Field Parameters in einer Matrix den zuletzt gewählten Hierarchie-Stand, wenn zwischen unterschiedlichen Gruppierungen umgeschaltet wird. (Stand 2026-02) Markus hat sein erstes Update-Video im Mai 2019 veröffentlicht. (Stand 2025-05)

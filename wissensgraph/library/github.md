# GitHub

In Unternehmen muessen Tools wie GitHub Copilot und Visual Studio Code bei jedem Entwickler einzeln installiert werden, was angesichts unterschiedlicher Nutzergruppen in Fabric eine Huerde ist. (Stand 2026-08) Der Agent Hub ist ueber die Anmeldung bei GitHub Copilot mit den dort verfuegbaren Modellen verbunden und speichert fruehere Prompts zur Wiederverwendung. (Stand 2026-08) Das Referenzmodell samt Monitoring-Dashboard wurde in einem GitHub-Repository bereitgestellt, damit es heruntergeladen und wiederverwendet werden kann. (Stand 2025-08)

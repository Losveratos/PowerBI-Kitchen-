# Dashboard Design

Die neuen Quicktipps funktionieren auch auf Kacheln. Der maximale Wert für die Breite eines visuellen Rahmens um ein Visual in Power BI beträgt 99. In Power BI gibt es vier Standardvisualisierungen mit horizontalen Balken: gestapelte, gruppierte und 100%-gestapelte Balkendiagramme sowie das Trichterdiagramm.

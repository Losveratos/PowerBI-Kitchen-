# Lizenzen

Echtzeit-Dashboards innerhalb von Microsoft Fabric sind laut Brian Bønk kostenlos und benötigen keine gesonderte Lizenz für die Visualisierung. (Stand 2025-09) Für Echtzeit-Dashboards ist laut Brian Bønk keine Power-BI-Pro-Lizenz nötig, es genügt mindestens eine F2-Fabric-Instanz. (Stand 2025-09) Ein eigener Workspace in Power BI erfordert eine Power BI Pro Lizenz, die kostenlose Lizenz berechtigt nur zur Nutzung des persoenlichen My Workspace. (Stand 2025-10)

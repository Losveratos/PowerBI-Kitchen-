# Translytical Task Flows

Translytical Task Flows sind jetzt allgemein verfügbar (Generally Available) und nicht mehr nur als Vorschau. (Stand 2026-03) Die Anbindung von User Data Functions an Translytical Task Flows für native Writeback-Logik in Power BI wurde auf der FABCON selbst nicht explizit erwähnt, steht aber weiterhin für Q2 auf der Fabric-Roadmap. (Stand 2025-04) Translytical Task Flows sind jetzt allgemein verfügbar (GA) und bauen auf den vorherigen GA-Schritten von SQL in Fabric, User Data Functions und Input Slicer auf.

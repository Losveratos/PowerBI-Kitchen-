# Data Agent

Auf der Ignite wurden Ontologien und Fabric IQ als neue Objekte innerhalb von Fabric vorgestellt, ergänzt um handelnde Operations Agents. (Stand 2026-01) Fabric Data Agents nutzen bereits bestehende semantische Modelle als Kernfeature für ihre Funktionsweise. (Stand 2026-01) Ontologien lassen sich direkt aus bestehenden semantischen Modellen erstellen, um vorhandenes Modellwissen wiederzuverwenden. (Stand 2026-01)

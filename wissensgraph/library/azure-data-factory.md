# Azure Data Factory

Weder Synapse mit Data Factory noch Fabric ersetzen automatisch Sonderzeichen in Spaltennamen, um Parquet-kompatible Namen zu erzeugen. (Stand 2025-05) Bei Azure Data Factory heißt das Gateway-Äquivalent Integration Runtime, eine andere Software als der Gateway für Power BI und Fabric. (Stand 2025-05)
